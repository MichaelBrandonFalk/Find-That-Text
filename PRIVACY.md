# Privacy

Find That Text processes videos locally on your computer.

Videos, screenshots, OCR results, filenames, and reports are not uploaded by Find That Text.

The application does not require an account.

The application does not include analytics or advertising.

When the optional ONNX Runtime backend is present, Find That Text sets `ORT_DISABLE_TELEMETRY=1` before OCR initialization.

If a future build uses a first-launch model download, that network behavior must be disclosed here before release. The preferred release model is to bundle the tested OCR model and runtime into the macOS application.
