Forced text review for Apple Silicon

Find That Text

Find opening titles, messages, signs, and other screen text that may need forced captions, without rewatching the entire movie.

Download for Apple Silicon Read README GitHub Repo

Latest release lookup will use GitHub Releases when published.

macOS 14 or newer. No account, uploads, or analytics.

How It Works

  1. Drop in a video.
  2. Add optional English or Spanish SRT/VTT captions.
  3. Scan locally with extra attention to dialogue-free moments.
  4. Review likely forced text first.

Outputs

  • Ranked candidate report
  • Likely, review, and background sections
  • Evidence screenshots
  • CSV and raw OCR audit data

Before or after dialogue captions

Captions help, but they are never required.

Use an English or Spanish subtitle file to scan quiet gaps more closely, or run a uniform scene-aware scan before the rest of the localization workflow begins.

Private by default

Video, captions, screenshots, and OCR results stay on your Mac. Download the Apple Silicon DMG, drag Find That Text into Applications, and open it. If macOS identifies the build as unsigned, use Open or Open Anyway.
