Find That Text v1.0.0

Apple Silicon macOS utility

Find visible text anywhere in a video.

Drop in a MOV or MP4, scan locally with PaddleOCR, and review every timestamped text event in CSV, HTML, screenshots, and raw JSON.

Download for Apple Silicon Read README GitHub Repo

Latest release lookup will use GitHub Releases when published.

How It Works

  1. Drop in a video.
  2. Scan it locally.
  3. Review every detected text event.

Outputs

  • Timestamped CSV
  • Searchable HTML report
  • Evidence screenshots
  • Raw OCR data

Privacy

Your video never leaves your Mac. Find That Text has no account requirement, advertising, or analytics.

Install

Download the Apple Silicon DMG from the latest release, drag Find That Text into Applications, and open it. If an unsigned build is provided, use macOS Open or Open Anyway. Do not disable Gatekeeper globally.
