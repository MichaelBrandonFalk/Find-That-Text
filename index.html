Best route for a feature

A smooth first run

The default scan checks every 23rd frame and, with English or Spanish captions, inspects dialogue-free gaps. Music and sound-effect-only cues remain scan time. Frame interval and gap-only scanning are separate settings, so you can widen coverage when needed.

  1. Choose your video. Add an SRT or VTT dialogue file if you have one. A matching caption file beside the video is picked up automatically.
  2. Keep the defaults. Leave Screen-text scan, Fastest - every 23 frames, and Scan only where dialogue captions are absent selected. Leave the end time blank for the full movie.
  3. Try a short range first if you like. Set an end time around ten minutes to check results, then clear it for the full scan. A late range jumps to that point instead of decoding from the start.
  4. Review the strongest matches first. Open the report's Likely Forced Text section, then Needs Review. Background graphics and credits stay available, but out of your way.

Need only a list of dialogue-free timecodes? Choose Super Speed Run - dialogue gaps only. With SRT/VTT captions, it exports an HTML timeline and CSV without decoding frames or running OCR; it does not find screen text. Without captions, the default scan checks the full video every 23 frames. Gap-only scanning can miss text shown during speech, and unusual caption labels may need review. Scanning a two-hour feature in two hours or less is a target, not a guarantee.

Before or after dialogue captions

Captions help, but they are never required.

Use an English or Spanish SRT/VTT dialogue file for the fastest gap-only scan, or scan the full video at the same 23-frame interval before the rest of the localization workflow begins.

Under the hood

What powers Find That Text

  • VideoFFmpeg via PyAV 18.1.0
  • OCRPaddleOCR 3.7.0 with PP-OCRv6 small models
  • Optional scene detectionPySceneDetect 0.7.1
  • Mac interfacePySide6 6.11.2

Private by default

Video, captions, screenshots, and OCR results stay on your Mac. Download the Apple Silicon DMG, drag Find That Text into Applications, and open it. If macOS identifies the build as unsigned, use Open or Open Anyway.
