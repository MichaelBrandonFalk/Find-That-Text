Find That Text v1.1.0

Private video OCR for Apple Silicon

Find visible text anywhere in a video.

Drop in a video, scan it locally, and get a clear timestamped report of every text event.

Download for Apple Silicon Read README GitHub Repo

Latest release lookup will use GitHub Releases when published.

macOS 14 or newer. No account, uploads, or analytics.

How It Works

  1. Drop in a video.
  2. Choose scan speed and text strictness.
  3. Scan it locally.
  4. Review every detected text event.

Outputs

  • Timestamped CSV
  • Searchable HTML report
  • Evidence screenshots
  • Raw OCR data

Built for private review

Your video stays on your Mac.

Find That Text scans locally, with no account requirement, advertising, or analytics.

Install

Download the Apple Silicon DMG from the latest release, drag Find That Text into Applications, and open it. If an unsigned build is provided, use macOS Open or Open Anyway. Do not disable Gatekeeper globally.
