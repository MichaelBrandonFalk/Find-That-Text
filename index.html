Best route for a feature

A smooth first run

Start with the recommended scan. It checks scene changes and samples the movie without the cost of examining every frame. An existing English or Spanish caption file helps it focus on quiet moments, but is not required.

  1. Choose your video. Add an SRT or VTT dialogue file if you have one. A matching caption file beside the video is picked up automatically.
  2. Keep the defaults. Leave Recommended - adaptive scan and Scan dialogue gaps more closely selected. Leave the end time blank for the full movie.
  3. Try a short range first if you like. Set an end time around ten minutes to check the results, then clear it for the full scan. Save every-frame and custom intervals for targeted rescans.
  4. Review the strongest matches first. Open the report's Likely Forced Text section, then Needs Review. Background graphics and credits stay available, but out of your way.

The scan runs locally. Scanning a two-hour feature in two hours or less is a design target, not a guarantee; actual time varies with the movie and Mac.

Before or after dialogue captions

Captions help, but they are never required.

Use an English or Spanish subtitle file to scan quiet gaps more closely, or run a uniform scene-aware scan before the rest of the localization workflow begins.

Private by default

Video, captions, screenshots, and OCR results stay on your Mac. Download the Apple Silicon DMG, drag Find That Text into Applications, and open it. If macOS identifies the build as unsigned, use Open or Open Anyway.
