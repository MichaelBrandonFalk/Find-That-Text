# Release Checklist

Verify each item before publishing release binaries.

- [ ] Version and Git tag match
- [ ] CHANGELOG updated
- [ ] Unit tests pass
- [ ] Integration tests pass
- [ ] OCR test fixture passes
- [ ] 1080p video tested
- [ ] 4K video tested
- [ ] MOV tested
- [ ] ProRes MOV tested if supported
- [ ] MP4 tested
- [ ] CSV verified
- [ ] HTML verified
- [ ] SRT caption optimization verified
- [ ] VTT caption optimization verified
- [ ] No-caption fallback verified
- [ ] Scene-change sampling verified
- [ ] Likely / Review / Background bucketing verified
- [ ] Screenshots verified
- [ ] Raw JSON verified
- [ ] Packaged `.app` tested
- [ ] DMG tested
- [ ] License audit completed
- [ ] Privacy statement accurate
- [ ] GitHub README complete
- [ ] GitHub Pages site complete
- [ ] Download link tested
- [ ] SHA-256 generated
- [ ] Git tag matches application version
- [ ] Release published
